#Weather and Information Chatbot
->A simple python-based chatbot that provides weather information and general information using external API's like Weather API 
and wikipedia
#Features
->Gets the weather for current location
->Displays weather condition and temperature
->Search Wikipedia for general information
->Interact with the application in an terminal based chat bot
->Uses API's to fetch data 
#Technologies Used
->Python
->WeatherAPI – for weather information
->Wikipedia – for general information
->Requests – for making API requests
->Git & GitHub – for version control
